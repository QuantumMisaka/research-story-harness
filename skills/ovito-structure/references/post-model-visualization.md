# 构模后检查与出图

适用于 Agent 已生成或修改结构、需要检查模型并决定是否制作静态图的任务。

1. **确认模型身份**：保留结构来源、单位、元素/占据率、晶胞/PBC，以及是否弛豫；区分计算结构和明确标注的理想示意。
2. **交互检查**：VS Code WSL 已安装 MatterViz 时，打开生成的结构文件，检查整体几何、界面/吸附位点、孤立或重叠原子及元素组成。MatterViz 的自动键仅是显示推断，不代表模型中的真实成键。
3. **出版渲染**：需要论文或报告静态图时，用原结构和 OVITO `render-spec` 渲染，保留 `scene.json`；按目标尺寸复核遮挡、比例、颜色和关键位点。
4. **核对表达边界**：结构读取/坐标一致性、模型科学有效性和图像可读性分别判断。渲染成功或视图美观不验证结构构造、计算收敛或机理。

MatterViz 查看 ExtXYZ 时若显示盒体或自动连接干扰判断，可另制 XYZ 预览副本；保留原文件，并确认副本的元素顺序与笛卡尔坐标未变。没有 MatterViz 时，用 OVITO draft 预览后再决定是否输出 final。
